const { height, width, left, top } = ref.current.getBoundingClientRect();
const middleX = e.clientX - (left + width / 2);
const middleY = e.clientY - (top + height / 2);
x.set(middleX * 0.3); // עוצמת המגנט
y.set(middleY * 0.3);
};
const handleMouseLeave = () => { x.set(0); y.set(0); };
return (
<motion.div ref={ref} onMouseMove={handleMouseMove} onMouseLeave={handleMouseLeave} style={{ x: mouseXSpring, y: mouseYSpring }} className="inline-block cursor-pointer">
{children}
</motion.div>
);
}

export default function TypingEffect({ text }: { text: string }) {
const [displayedText, setDisplayedText] = useState("");
useEffect(() => {
let i = 0;
const interval = setInterval(() => {
setDisplayedText(text.slice(0, i + 1));
i++;
if (i === text.length) clearInterval(interval);
}, 100);
return () => clearInterval(interval);

## Concept
An editorial Apple product page, in the spirit of the AirPods Max campaign:
- one object photographed like a product
- a giant pale tone-on-tone word behind it
- a tight stacked headline
- small quiet body text
- one soft neumorphic pill button
- a cropped macro detail bleeding off the edge
Monochrome, calm, lots of air, nothing decorative.
There is NO UI in the hero: no cards, no device mockups, no chips, no badges, no icons, no color gradients, no glows. If something looks like a template, remove it.

## Motion (quiet, plays once, Apple restraint)
Easing everywhere: cubic-bezier(0.22, 1, 0.36, 1).
- Load:
- ghost word fades in, 0→1 over 1.2s
- the object rises 24px→0 and fades in (900ms, delay 150ms)
- the text lines fade up 12px, with an 80ms stagger
- the macro slides up 40px→0 (1s, delay 300ms)
- The accent detail on the ghost word appears last (scale 0→1, delay 1.1s). It's the only "event" on the screen.
- Idle: the object floats very slowly, translateY 0 → -8px → 0 over 6s, infinite, ease-in-out. Nothing else moves.

- Pointer (desktop only): the object shifts at most 8px toward the cursor, the ghost word at most 4px the opposite way.

## STEP 7 — src/can.js (the 3D can)
1. **Renderer** on `#can-canvas`: alpha, antialias, pixelRatio `min(devicePixelRatio, 2)` (1.5 on mobile), `SRGBColorSpace`, `NeutralToneMapping`, exposure .95.
2. **Scene:** environment = `RoomEnvironment` through `PMREMGenerator`, `environmentIntensity .45`. White DirectionalLight 1.3 at (-4, 6, 5) + AmbientLight .35. **Camera:** PerspectiveCamera fov 25, z = 12.
3. **Groups:** `canGroup` (rotation.order `'XZY'`) → `floatGroup` → model. With this order +rx tilts the top toward the camera (lid visible) and +rz leans the top to the LEFT.
4. **Load** `/models/can.glb` with GLTFLoader + DRACOLoader (decoder `https://www.gstatic.com/draco/versioned/decoders/1.5.7/`). Wrap it in a `fix` group: rotate so its longest axis points up Y; if `FLIP` rotate π on X; rotate `FRONT_Y` degrees on Y; scale to height 1; move its bounding-box center to the origin. `FLIP` and `FRONT_Y` are consts at the top of the file, overridable by `?flip` and `?front=90`.
5. **Materials:** parts with a texture map: metalness max .25, roughness min .45, envMapIntensity .6. Parts without a map (lid, rim): metalness .9, roughness .3. If the GLB fails to load, build a fallback can (cylinder r .33 with a canvas gradient label + lathe top and bottom).
6. **Pixel → 3D:** `k = 2·tan(fov/2)·camera.z / innerHeight`. Position x = `(px − innerWidth/2)·k`, y = `−(py − innerHeight/2)·k`. Scale = `heightPx·k`.
7. **Pose from scroll** (every frame, read `window.scrollY`, keys = `getAnchors()`): find the two anchors you're between; `t = easeInOutQuad((scrollY − A.scroll)/(B.scroll − A.scroll))`. Position x/y, rx and rz follow a quadratic curve that passes through a middle waypoint M at t = .5 (control point = 2M − (A+B)/2). Height and ry go linear. Add a spin of `t·360°` on Y. Waypoints — desktop: hero→flavour `(40vw, 68vh, rx 6, rz 2)`, flavour→fresh `(40vw, 47vh, rx 6, rz 0)`; mobile: `(50vw, 60vh)` and `(50vw, 45vh)`. Before the first anchor or after the last, hold that anchor's pose.
8. **Intro:** when both the model is loaded and the `intro:can` event fired, tween `p` 0 → 1 over 1.4s power3.out. Apply offsets × (1 − p): 12vh lower, rz +25°, ry −90°, scale ×.85. Opacity = min(1, p·2.5) (materials transparent during the intro only).
9. **Idle:** floatGroup y = sin(t·1.2)·.02, rz = sin(t·.9)·1.5°; desktop mouse parallax max 3° on Y and 2° on X, smoothed .06. Clamp all idle rotation to ±3°.
10. **`?upright`:** show the can centered, height 50vh, rotation 0, no idle — for calibration.
11. Render on `gsap.ticker`. Rebuild anchors + camera aspect on `anchors:refresh`.
