# LALIBAKERY

אתר עוגות בעברית (RTL) ל־**LALIBAKERY** — אפייה מהלב.

קטגוריות:
- **עוגות גן** — מלבניות עם דף אכיל / דמויות
- **עוגות מספרים** — ספרות עם קרם, פירות ושוקולד
- **עוגות מעוצבות** — עגולות ושכבות עם טופרים וכתרים

## הרצה

```bash
npm install
npm run dev
```

האתר: [http://127.0.0.1:43127](http://127.0.0.1:43127)

טלפון / וואטסאפ: **050-8739090**

## תוכן

תמונות אמיתיות ב־`public/cakes/` לפי קטגוריה. הלוגו ב־`public/cakes/brand/logo.jpg`.
